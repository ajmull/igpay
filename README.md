# Igpay
Igpay is a simple, bare, lightweight translator for pig latin. It can only translate from plaintext to pig latin, not vice versa.
Also, Igpay cannot have input piped into it.

# Use
Igpay is relatively simple to use: `igpay PLAIN`. `PLAIN` can be any string: `igpay "Hello, amazing world!`.
Igpay removes all punctuation and case: `igpay "Hello, amazing world!"` results in `"ellohay amazinghay orldway"`.

## As a Library
Igpay can also be used as a dependency for other projects, as its library has a simple-to-use API. For more info on this, see the documentation.
